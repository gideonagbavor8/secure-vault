# SecureVault — Password & Secrets Manager

A full-stack SecureVault project built with Next.js 14 (App Router), TypeScript, Tailwind CSS, shadcn/ui, and a Node.js + Express backend API.

## Project Structure

- `/frontend` — Next.js 14 application (Frontend)
- `/backend` — Node.js + Express application (Backend API)

## Getting Started

### Backend
1. Navigate to the backend directory: `cd backend`
2. Copy `.env.example` to `.env`: `cp .env.example .env`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`

### Frontend
1. Navigate to the frontend directory: `cd frontend`
2. Copy `.env.example` to `.env`: `cp .env.example .env`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
